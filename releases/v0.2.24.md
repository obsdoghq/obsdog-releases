# ObsDog CLI v0.2.24

This maintenance release preserves schema 12, historical evidence, ranking and
sync formats. Already-transitioned libraries need no repeat migration. Existing
schema-11 libraries still need the separate, backup-first
[11 → 12 transition](../guides/local-schema-migration.md).

## Changes

- A sync delta page exceeding the existing response byte limit retries with
  fewer items at the same checkpoint. Invalid responses and a single oversized
  operation still fail explicitly; pending work and checkpoints are preserved.
- Identifier navigation hints recognize acronym boundaries and file basenames
  while preserving Korean-compound hints. They remain bounded suggestions,
  separate from retrieval hits, answers and usage observations.
- Standalone updates initiated by v0.2.24 retain a verified copy of the previous
  executable before replacement. The JSON result includes a relative recovery
  path and copy digest. Copies remain private, non-executable and outside PATH;
  check-only calls create no recovery artifacts. Unsafe or conflicting recovery
  state refuses replacement rather than overwriting evidence.

The retained executable is a same-filesystem byte copy, not proof of artifact
authenticity, a database backup or permission to run an older writer against an
upgraded library. Complete recovery still requires compatible data, private
backups and paused writers. Copies are never automatically run or pruned.

## Installation and updates

Apple silicon macOS and Linux x86_64 remain supported. Both CLI archives and
their separate 11 → 12 transition tools have SPDX inventories in the same
immutable checksum manifest. Installation never signs in, uploads knowledge,
migrates an existing library or terminates agents.

Use `brew upgrade obsdoghq/tap/obsdog` for Homebrew-owned installations or
`obsdog update` for standalone installations. Homebrew check-only results keep
their package-owner instruction. Reconnect client-owned MCP sessions and
restart owned dashboards with their previous flags; a shell or browser refresh
does not replace an already running process.

No Windows binary, native-app release, new storage transition or measured
performance/retrieval-quality improvement is claimed.
