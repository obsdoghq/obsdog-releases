# CLI v0.1.12 — one recoverable Personal Space

This release adds an explicit, owner-authorized path to combine an offline
Personal library with an existing hosted Personal without re-importing current
Markdown or discarding revision and evaluation history.

- `space prepare --id` creates an empty canonical hosted candidate without
  changing your default or uploading anything.
- `sync adopt-preview` checks an exact private backup against the destination.
- `sync adopt --plan` preserves the source read-only, commits idempotently,
  verifies server archive readback and restores historical evidence locally.
- `space activate-adopted --plan` changes the default only after verified
  restoration and a complete hosted download.
- Fresh clients restore retained archives before later changes. Old clients
  receive an explicit recovery error instead of silently skipping knowledge.
- Upload acknowledgements no longer advance the applied download checkpoint.
  Repeated empty pulls are no-ops; broken download chains fail explicitly.
- Early hosted traces with incomplete evidence are labeled partial. Missing
  query, ranking and index evidence is never invented.

The advanced adoption workflow requires server v0.1.24 or newer and consent to
upload the **entire source history**, including queries, comments and feedback.
Keep private backups. Resume the same plan after a lost response; never manually
rewrite IDs, delete a source or unfreeze uncertain work. Supported input is stable
schema 1–10 with no sync transport or unsupported auxiliary histories, bounded
to 16 MiB zipped / 64 MiB expanded. Unsupported inputs fail without overwriting.
Hosted storage/operation quotas still apply. This is managed sync, not E2EE.

Local-only use still needs no account, network or `init`. Existing local schema
versions stay at 1–10; compatibility feature tables are separate. No background
upload is enabled by installing. Mac desktop and iOS work remain on hold.

Apple silicon macOS CLI only. Source remains proprietary. The archive includes
license notices, SPDX inventory, exact source revision and SHA-256 manifest;
it is not a notarized desktop application.
