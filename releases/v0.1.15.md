# v0.1.15 — newline-safe block updates

This patch corrects v0.1.14's overly strict content-only update validation.
Markdown replacement files may end in normal LF/CRLF newlines; outer whitespace
and CRLF are normalized using the same rules as document import. Paragraph,
heading, list-item and fenced-code replacements are covered by regression tests.

Multiple Markdown blocks, type/depth changes and stale base revisions remain
rejected before writing. Original revisions and portable import consistency are
preserved. CLI subprocess tests cover actual `block update --file` input.

Source-aware care, actor attribution, default Personal storage and the server
v0.1.26 compatibility requirement are unchanged. No database migration, automatic
upload, native app update, plugin installation or background maintenance is added.

Standalone users: `obsdog update`. Homebrew users: `brew update` then
`brew upgrade obsdoghq/tap/obsdog`. Choose one installation owner.
