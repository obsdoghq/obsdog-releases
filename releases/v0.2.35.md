# v0.2.35

This release adds explicit structural Care and clearer contention diagnostics.

- Retire complete sections, add headings to existing documents, reparent subtrees and transfer disjoint roots between documents with successor lineage. Read-only checks precede atomic changes. Exact request replay and bounded compensation retain history.
- Use separate `space write-readiness` or stdio MCP `obsdog_write_readiness`. Ordinary status remains a read-only snapshot; a successful probe reserves no later write. Writer identity and age stay unknown when unavailable.
- Search open/use/feedback share bounded admission diagnostics. Operation/phase, waits and elapsed time distinguish paths. An unobserved fallback is not counted as an observation.
- Inspect known offending source block IDs and JSON field paths; `care schema` describes accepted plan fields. Ordinary update/merge errors show parsed or expected type/depth without flattening paragraphs.
- Restore retention checkpoints containing retired predecessors without colliding with active block positions. History, compensation and compatibility floors remain intact.
- Doctor compares caller-declared loaded guidance with its bundled baseline. A plugin update does not upgrade the CLI/server or refresh session instructions.

See the [structural Care and recovery guide](../guides/structural-care.md). Connected structural Care requires compatible active consumers and authenticated preparation. New receipts permanently block older writers/readers for that Space, including after compensation or recovery. Local-only use needs no server or account.

Includes v0.2.34 capture-draft recovery, code-aware reference checks and separate explicit storage transition helpers. Installing does not automatically transition an existing library. This release makes no claim to have identified every intermittent contention cause or improved a particular user's timings.

Standalone CLI: macOS arm64 and Linux amd64. Native desktop/mobile release status is separate. Binary licenses, notices, SPDX files, source revision and checksums are included.
