# ObsDog CLI v0.2.25

This maintenance release improves sync pull when recorded retrievals refer to
historical revisions missing from the receiving library. A compatible server
supplies verified original ancestry, and the client retains it while applying
the same staged changes. Retrieval history does not replace current content.

If the original history is unavailable or cannot be verified, pull fails while
preserving pending work, downloaded changes and checkpoints. Keep your backup
and retry the same pull after the service is available. Do not discard local
changes or reset the library to retry.

Schema 12 and existing writer compatibility remain unchanged. A library already
on schema 12 needs no repeat migration. Older schema-11 libraries still require
the separate, backup-first [11 → 12 transition](../guides/local-schema-migration.md).

Apple silicon macOS and Linux x86_64 remain supported. The immutable checksum
manifest includes both CLI archives, their separate transition tools, SPDX
inventories and license notices. Installation does not sign in, upload knowledge
or migrate an existing library.

Use `obsdog update` for standalone installations or
`brew upgrade obsdoghq/tap/obsdog` for Homebrew-owned installations. Reconnect
client-owned MCP sessions and restart owned dashboards to load the new runtime.
