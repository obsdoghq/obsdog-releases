# ObsDog CLI v0.1.8 — local free beta

Apple silicon macOS only; local use needs no account or GitHub login. This is
the terminal CLI, not the notarized macOS desktop app.

## Changes

- Fix macOS archive packaging so the existing strict updater can install the
  release. v0.1.7 is superseded and its assets remain unchanged.
- Search, opening and explicit evidence use accept `--actor-type human|agent`
  and `--actor ID`. Agent CLI activity remains source `cli`; private traces show
  the recorded actor ID. Historical records are not relabeled.
- New/repaired project guidance includes explicit AI attribution in both
  `AGENTS.md` and `CLAUDE.md`. A binary update does not rewrite project files.
- Discover/create profile-owned Spaces independently of a project directory.
- App-owned helpers refuse standalone self-updates; their whole app owns them.

```sh
obsdog update --check
obsdog update
obsdog search --query "your terms" --actor-type agent --actor your-agent --format json
```

Use the same actor options on `search open` and `search use`. Record only actual
inspection/use, and use `--evaluator-type agent --evaluator your-agent` for AI
feedback. JSON output alone does not identify an AI caller. Review
`obsdog init --dry-run` before using `obsdog init --repair` to refresh an existing
project's managed instructions.
