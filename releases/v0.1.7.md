## Changes

- Search, open and evidence-use commands accept `--actor-type human|agent` and
  `--actor ID`. Agent CLI activity stays source `cli`; private traces retain the
  actor ID. Feedback still needs its separate evaluator flags.
- New/repaired `AGENTS.md` and `CLAUDE.md` guidance includes agent attribution.
  Updating the binary does not silently edit project instructions.
- Discover and create profile-owned Spaces without requiring a project folder.
- App-owned CLI helpers refuse independent self-updates; the whole app owns them.

```sh
obsdog update --check
obsdog update
obsdog search --query "your terms" --actor-type agent --actor your-agent --format json
```

Use the same actor options on `search open` and `search use`. Only record actual
inspection and use. AI judgments use `feedback add --evaluator-type agent
--evaluator your-agent`; they must never be counted as human feedback. Review
`obsdog init --dry-run` before using `obsdog init --repair` in an existing project.
