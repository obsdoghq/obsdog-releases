## Offline visibility and easier first use

- `obsdog dashboard serve`: bundled local Overview, Knowledge/Wiki, Graph, Activity and Sources at `http://127.0.0.1:47777`. No login, sync, external assets, analytics or hosted-network bridge. English/Korean, light/dark, keyboard and reduced-motion support.
- Recorded Top 1/3/10 utilization and observation coverage, equal-period comparisons, useful ratings, direct edits and restructuring. Unknown use is not failure; edit counts do not prove quality gains. Historical page numbers are not inferred.
- Whitespace-insensitive, Unicode-normalized substring search: `사과` finds `사과나무`; `사과나무` finds `사과 나무`. Source text and retained traces remain unchanged. Matching policy is `lexical/compact-substring-v1`; this is not semantic search or a benchmark gain claim.
- `obsdog document list` for IDs, titles and block counts; `obsdog insights show` for local read-only JSON measurements.
- `obsdog care source` records revision-bound source checks, including private-clone version/scope/evidence, through typed options. It does not crawl private URLs or automatically certify prose notes.

The plugin and CLI are separate installations. Run `obsdog version`, then verify an installed skill in a fresh client session. [Setup guide](https://github.com/obsdoghq/skills/blob/main/docs/SETUP.md) · [Product feedback](https://github.com/obsdoghq/obsdog-releases/issues/new/choose).

### Safety and scope

The local service binds loopback only and rejects foreign Host/Origin access. Do not reverse-proxy it. Overview views fabricate no search/use/evaluation events; explicit Wiki search/open actions retain attribution. Existing HTML reports remain untouched, with export still available on explicit request.

Immutable history, exact hit revisions and numbered storage schema are retained. Restart any old CLI MCP/viewer process after upgrading. Hosted application behavior is not changed by installing this CLI. Native app builds are not included.

### Verification

Full race tests and vet, substring and source-care regressions, run deduplication/actor/window checks, local security/observation tests, responsive browser QA with loopback-only requests, restored-copy history integrity and actual packaged-archive decoding pass. Quality benchmarks remain separate; no improvement percentage is asserted.
