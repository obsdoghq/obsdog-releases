# ObsDog CLI v0.2.23

This maintenance release preserves v0.2.22's schema 12, historical evidence,
search policy and sync format. Already-transitioned libraries need no repeat
migration. Existing schema-11 libraries still need the separate, backup-first
[11 → 12 transition](../guides/local-schema-migration.md).

## Corrections

- Complete sync tails apply structural events in their recorded receipt order,
  retaining atomic rollback for malformed or conflicting operations.
- Repeated label assignments and reviews must match their original immutable
  receipt. A conflicting reuse is rejected rather than silently accepted.
- Hosted OAuth operations use the access token and device identity from one
  credential resolution, including refresh or concurrent credential replacement.
- History connection failures expose bounded timeout, DNS, TLS or connection
  diagnostics without printing credentials, URLs or private response bodies.
  Retained work stays available; do not clear queues to work around a failure.
- Recent Care runs sort by the exact recorded instant, including fractional
  seconds and timezone offsets, while preserving original timestamp text.

## Label review diagnostics

`label list` distinguishes pending review from stale, superseded or unavailable
targets. `label suggestions --limit 50` returns a bounded, read-only worklist;
use its returned `--after` cursor for another page in the same Space.
Diagnostics do not approve labels, rewrite evidence or waive protected review.

## Installation and updates

Apple silicon macOS and Linux x86_64 remain supported. The public distribution
includes both CLI archives, matching SPDX inventories and separate 11 → 12
transition tools in the same checksum manifest. Installing never signs in,
uploads knowledge, migrates an existing library or terminates agents.

Use `brew upgrade obsdoghq/tap/obsdog` for Homebrew-owned installations or
`obsdog update` for standalone installations. Reconnect client-owned MCP
sessions and restart owned dashboards with their previous flags. Check
`obsdog_version` in the existing MCP connection and `obsdog dashboard status`;
a fresh shell or browser refresh does not replace an old process.

Review only the ObsDog section of AGENTS.md / CLAUDE.md against the
[agent update checklist](https://github.com/obsdoghq/skills/blob/main/docs/SETUP.md#updating-cli-and-agent-guidance).
The separate plugin still provides `find`, `remember`, `maintain` and
`documentify`; this CLI patch adds, removes or renames no skill.

No new storage transition, ranking change, native-app release or measured
performance/answer-quality improvement is claimed.
