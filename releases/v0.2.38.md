# v0.2.38

This release makes accepted work and failed correction recovery explicit.

- Failed ordinary edits report transaction evidence and a separately bounded fresh
  revision, including an explicit unknown outcome. Retry only the failed target;
  keep the original receipt key and preserve already accepted sibling writes.
- Private local correction drafts retain original content, actor and revision
  bases. Inspect, recover or explicitly resolve them after manual reconciliation.
  Read notices describe this installation; they are not synchronized verification.
  Preserve correction files separately from database-only Space backups.
- Single-shot commands share a default 60s cancellation deadline. Prefix
  `obsdog --timeout 90s ...` to override it. Failed mutation reconciliation can
  use a separately disclosed maximum 500ms read-only check.
- Read content, mutation, search observation and Care receipt acceptance are
  distinct. A refused open can return content without satisfying use/feedback.
  Retry only that original open after writer release.
- Writer samples identify their admission attempt and avoid contradictory
  positive-PID/unavailable-probe values. Unknown transaction age stays unknown.
- Current inventory excludes settled redirects and always states lifecycle.
  Doctor excludes settled duplicate groups and marks outdated release caches.
- CLI stderr can warn about an older same-Space default-port dashboard.
  `dashboard restart` stops only authenticated owned control. Older listeners
  without that control need one manual foreground stop; no PID is guessed.

Read [accepted work and recovery](../guides/accepted-work.md). Installing this
release does not enable a policy, migrate data, change another library or reload
an existing agent/MCP/viewer session. Check installed help and loaded guidance.

Standalone archives are provided for macOS arm64 and Linux amd64. Native macOS
execution validation was waived for this release; archive presence does not imply
completed native qualification. Checksums, SPDX, licenses, notices and exact
source revision accompany the binaries.
