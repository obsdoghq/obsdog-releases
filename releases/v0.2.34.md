# v0.2.34

This release improves capture recovery, split safety and command diagnostics.

- Recover an unsuccessful Markdown import with `document drafts` and `document recover --draft ID`. Recovery reuses the original request and committed receipt, preserving Space, actor and document identity without creating a second document. Private drafts remain available for inspection; new imports are separate create intents.
- Use `document split --dry-run` for a read-only check. `--with-title-heading` explicitly creates an H1-led root document atomically with extracted lineage. It requires title-extraction-capable active consumers; adopting it blocks older writers/readers for that Space. Update and check long-running MCP/viewer processes separately before using it.
- Reference checks exclude actual Markdown code spans and code blocks. Supported existing paragraph terminal newlines retain their exact original bytes.
- Status and diagnostic searches remain readable during writer contention. A normal search can return an explicitly unobserved result after confirmed admission refusal; it has no recorded search run. Never report these hits as successfully observed or used.
- Search rejects options placed after a positional query before selecting a Space or recording observations. Put options first, prefer `--query TEXT`, or use `--` for literal option-looking query words.
- `doctor` distinguishes running/installed CLI facts, caller-declared loaded guidance and required capabilities. Latest-release lookup requires `--check-updates`. A plugin update does not upgrade the CLI/server or refresh an already running session.

Includes the v0.2.33 storage format support and separate explicit schema12→13 transition helper. Installing this CLI does not automatically transition an existing library. Preserve backups and check every active consumer before an explicit transition or new compatibility floor.

One document update provides one exact-base atomic publication; it is not a universal speed guarantee. This release makes no claim about a particular user's latency or storage savings.

This is the standalone CLI for macOS arm64 and Linux amd64. Native desktop and mobile applications have independent release status. Binary licenses, notices, SPDX files, source revision and checksums are included.
