# ObsDog CLI v0.2.12

This update prevents a direct `block split` or `block merge` from committing a
successor whose Markdown kind or whole-document layout disagrees with its stored
structure. `obsdog doctor` can now list bounded stored-versus-rendered layout
mismatches in older documents. It is a read-only diagnosis, not a repair: do not
retry a rejected edit with a new import or modify the Space database directly.
Adding a heading or another new block kind still needs a reviewed structural
operation; this release does not silently change the meaning of `document
update`.

`obsdog search --no-observe --query ...` checks the current matcher, ranking and
filters without creating a retrieval run, event or metric. Its rows have no
run/hit receipt and cannot be opened or marked used. Use ordinary `obsdog
search` for task retrieval. The optional scoped MCP server exposes the same
diagnostic distinction as `obsdog_search_probe`.

Quoted terms require a contiguous match after whitespace removal. If a quoted
query returns no hit, the result may show how many bounded candidates removing
the quotes would expose; that count is a query hint, not an answer. Historical
trace search, lexical and ranking policy fields now all remain `unknown` unless
the original run recorded a complete policy receipt. New completion events
include the policy triple.

The local Graph organizes direct written-reference groups separately and keeps
documents without a visible authored link in the searchable title list. A
title-list selection focuses the map and shows direct neighbors. The layout
does not infer links, alter normal search ranking, or judge standalone notes as
low quality. A synthetic dense fixture passed local visual checks; this is not
a measured improvement for every real Space.

Installing or upgrading does not enable account login, cloud sync or migration.
After upgrading, restart running `obsdog mcp` and `obsdog dashboard serve`
processes, and reconnect existing agent sessions. A browser refresh does not
replace a running binary.
