# CLI v0.1.14 — source-aware knowledge care

Apple silicon macOS CLI free beta. This is a standalone terminal binary, not a
desktop application update. Product source remains private.

- `obsdog care show` reads revision-bound source declarations and authoring reviews.
- `obsdog care record --file care.json --actor-type agent --actor YOUR_AGENT`
  appends a typed source/review record with reason, evidence and retry identity.
- `obsdog search --source-role pointer --temporal current "installation"`
  filters before the result limit. Unknown, stale and conflicting provenance can
  also be selected explicitly; unfiltered search keeps legacy notes discoverable.
- Local Wiki source inspection, the read-only `obsdog_care_show` MCP tool, and
  private HTML reports distinguish provenance, authoring checks and task utility.
- Portable imports keep original assessments as archival evidence, never fresh
  verification of the newly imported revisions. Full backups retain exact history.
- A block update now rejects implicit Markdown structure changes instead of
  creating a block map that cannot be imported. Use explicit split/merge operations.

## Compatibility and meaning

Connected Spaces require server v0.1.26 and compatible active clients before the
first care write. Upgrade does not upload data, backfill provenance, run an AI
worker, install plugins or resume Mac/iOS application development.

Roles are native/pointer/derived/snapshot; temporal intent is
current/historical/working. Assessments bind to exact revisions and become stale
when content changes. Offline concurrent judgments remain conflicts until a
new justified record resolves them. A source URL loading successfully does not
prove claim correctness. AI and deterministic checks never impersonate people.

Coverage and 30-day reviewed-sample dimensions show unknown, N/A and unassessed
counts. They are not a whole-library quality score or proof of improved retrieval.
There is no automatic rank boost or deletion. Care inputs are bounded at 16 KiB;
each recorded/imported event class has a per-Space bound of 4096 events/8 MiB.
Use `obsdog care --help` and [the documentation](https://docs.obsdog.ai).

After care records are written, keep connected clients at v0.1.14+ and server at
v0.1.26+. Do not discard event history to downgrade. Keep recoverable backups.

## Install / update

Choose one installation owner. Standalone: use the checksum-verified installer
from this exact release, or `obsdog update`. Homebrew: `brew update` then
`brew upgrade obsdoghq/tap/obsdog`. Local use remains account-free and defaults to
Personal without `init`. Existing Space identities and knowledge are preserved.
