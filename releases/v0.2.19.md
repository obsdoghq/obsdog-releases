# ObsDog CLI v0.2.19

Identify the process you are actually observing after an upgrade:

```bash
obsdog dashboard status --port 47777 --format json
```

The read-only command compares the running viewer's version/channel with the
installed CLI and reports its Space, start time and `restart_required`. It
does not open a library, scan local ports, follow redirects or stop a process.
The existing viewer endpoint is `/_obsdog/health`, not `/api/version` or
`/healthz`; older compatible viewers may omit the start time. A missing or
unverifiable listener is an error, not proof that a current viewer is running.
Check `obsdog_version` inside an existing MCP connection separately.

The stable SQLite migration reduces safe derived copies and repeated event
eligibility checks. Only superseded, unobserved local search snapshots become
eligible after a one-hour grace period, in bounded batches. Canonical knowledge,
history, evaluations, current/remote snapshots and whole run-pinned snapshots
(including frozen later pages) are preserved. This is not a change to ranking
weights, a complete incremental score cache or a demonstrated hit-rate gain.
Ordinary CLI use performs the migration; passive dashboard reads do not migrate
or compact the library. Database files need not shrink: SQLite can reuse freed
pages. No destructive vacuum or separate database split is introduced.

**Before using an upgraded library, reconnect existing MCP sessions.** Stop and
rerun owned dashboards with their original Space/port flags, then verify status.
Schema 11 is not a supported downgrade to an old stable binary. Keep recoverable
backups; do not mix an old writer with the migrated library. This update does not
terminate user-managed processes or enable cloud synchronization.

Help and the care guide now distinguish deprecated-label hiding from supersede
retirement. `--include-deprecated` returns hidden **active** candidates, not
superseded retired blocks. Exact-ID reads, block history and original traces
retain evidence. No lifecycle-invalidation change was made for the withdrawn
P-1 allegation. Human `trace show` displays all three recorded policy stamps;
missing historical receipts remain unknown.

The companion plugin v0.3.15 adds these checks to existing workflows and the
update checklist. No skill was added, removed or renamed; the four workflows
remain `find`, `remember`, `maintain` and `documentify`.
