# v0.2.40

Search activity now uses consistent attribution in its counts and expanded
result stages. Previously, a result could say Used while the search showed
Used 0 when its raw use declaration did not qualify for that search's count.

- Opened/used counts include distinct exact results supported by the initiating
  actor's direct observations and valid recorded order.
- Other recorded declarations remain visible as recorded but not counted.
  The sequence shows each action's actor so differences can be inspected.
- Missing eligibility evidence is shown as unknown. A raw declaration alone
  does not establish counted use, human verification or usefulness.
- Existing history, metric definitions, local schemas and retention policies
  are unchanged. The dashboard remains read-only.

After upgrading the CLI, restart the running dashboard and refresh the page.
Browser refresh alone keeps the old server process. Use `obsdog dashboard status`
to compare the running viewer with the installed CLI. Supported owned viewers
can use `obsdog dashboard restart`; older foreground viewers need one manual
stop before starting `obsdog dashboard serve` again.

Standalone archives are supplied for Linux amd64 and macOS arm64. Additional
native macOS execution was waived; archive presence does not establish native
validation. Checksums, SPDX, licenses, notices and source revision accompany assets.
