# ObsDog CLI v0.2.0 — Space-only commands

Apple silicon macOS CLI beta. Local use needs no account or project setup.

## Breaking interface cleanup

- Removed `obsdog init`, `--path` and `--source-path`; there are no aliases.
- Omitted selection uses Personal, independent of the current directory.
  Use `--space personal` or `--space <exact-space-id>` explicitly. Invalid or
  missing explicit selections fail rather than switching libraries.
- `sync adopt-preview` now uses `--source-space <source-id>` and `--space <target-id>`.
  Whole-source upload consent, backups, reviewed plans and verification still apply.
- `space restore --backup FILE` validates privately and installs the archive's
  unchanged ID into the profile catalog. Existing destinations are never replaced.
  Restore does not change the default, enroll a device or transmit data.

```sh
obsdog document import --file ./notes.md
obsdog search --query "release rollback"
obsdog wiki serve
obsdog space list --format json
obsdog search --space <space-id> --query "specific topic"
obsdog mcp --space personal
```

Data stays in `~/.obsdog/spaces/<id>`. Existing revisions, measurements, backups,
credentials and sync identity are retained. No database schema, ranking policy
or sync-wire change is included. File options (`--file`, `--output`, `--backup`,
`--plan`) remain. Legacy project files/mappings are not deleted but no longer
select a Space: update scripts and agent instructions to use exact IDs.

If an older catalog lacks an unambiguous default, explicitly choose it with
`obsdog space default --set <space-id>`. Project-local legacy databases are not
silently migrated. For recovery while an ID already exists, restore into an
isolated `OBSDOG_HOME`; do not overwrite current knowledge or reassign IDs.

Standalone users update with `obsdog update`; Homebrew users use
`brew upgrade obsdoghq/tap/obsdog`. The shared Codex/Claude plugin 0.3.0 requires
this interface and keeps MCP disabled until the chosen Space is authorized.
Installing/updating the CLI does not install that plugin or enable cloud sync.

Source tests cover Personal/cwd isolation, removed flags without writes,
attribution, MCP subprocesses, retained history and restore collision/failure.
Packaging includes checksum verification, notices and SPDX inventory. Earlier
downloads and benchmark pins remain unchanged. Native apps/helpers are separate
and are not updated by this release. No quality-gain or general-availability claim.
