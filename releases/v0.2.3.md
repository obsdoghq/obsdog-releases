# ObsDog CLI v0.2.3 — stable result pages and connected references

- Continue a search with `search page --run ID --page N`. Page size and the
  bounded 100-candidate order are frozen; open/use/feedback keep global ranks.
  Reopening a page does not inflate observations or substitute edited text.
- First-page use has its own explicit numerator and page-aware denominator.
  Legacy searches remain excluded. An unobserved use is unknown, not a failure;
  edits and period changes do not by themselves prove retrieval improvement.
- The local graph and Wiki resolve exact imported relative paths in the same
  Space. Missing/ambiguous paths are not guessed. Current document/block question
  comments form a separate attributed proposal layer, not stronger citations.
- Agent feedback defaults now match the agent caller's default ID. Named agents
  should continue passing their own exact evaluator ID; past records are unchanged.
- `memory show --summary` provides compact observed query/co-use coverage.
  `search --exclude-headings` finds body blocks without treating heading opens
  as full-section reads. The document graph and observed-memory graph differ.

No account is required locally. No automatic import, sample injection, cloud
enrollment, sharing or background worker is enabled. Native apps are not included.
Connected users need a hosted service compatible with the new page metadata.
Continue a run on its original device if another device lacks retained chunks.

See [search pages](https://github.com/obsdoghq/obsdog-releases/blob/main/guides/search-pages.md), [the local dashboard](https://github.com/obsdoghq/obsdog-releases/blob/main/guides/local-dashboard.md)
and the separately installed [AI workflows](https://github.com/obsdoghq/skills).
Usefulness/ranking improvement remains an evaluation question, not a release claim.
