# ObsDog CLI v0.2.16

The offline Graph now shares the hosted app's visual system and reusable
components. Local knowledge still needs no account, upload or sync.

- Follow one connected component at a time, with settled circular nodes,
  direct-neighbor focus and a close-to-wide entrance along real written links.
  Click the selected point again to clear focus. Selection does not rearrange
  the graph or replay the entrance.
- Use the component selector or title/ID index to reach any loaded document,
  including independent notes. The overview thumbnail uses the same geometry.
- Follow exact source-block anchors from the inspector. Unconfirmed proposals
  and unresolved references remain distinct from authored connections.
- Refreshing unchanged data preserves the view; returning to a component
  restores its camera. Motion completion follows the actual visible effects;
  reduced-motion settings skip spatial animation. Large visible components
  use a lighter entrance, not a continuously running simulation.
- Embedded styles and modules load only from the loopback server, without
  remote fonts, scripts or analytics. Passive Graph interactions create no
  searches, uses, ratings or new knowledge.

Node size indicates authored neighbor count and line width counts distinct
source blocks; neither is a truth or usefulness rating. The existing bounded
view and truncation notices still apply. This update does not change search
ranking, synchronization policy, database schema or held native applications.

After upgrading, stop and rerun `obsdog dashboard serve` with the same Space
and port flags, then refresh the browser. Reconnect agent sessions that own
an `obsdog mcp` process. Replacing the CLI file does not replace running
processes. See the [dashboard guide](../guides/local-dashboard.md).
