# CLI v0.1.9

Packaging-only patch over v0.1.8: the installer defaults to v0.1.9, packaging
rejects a mismatched default, and public SBOM metadata omits local build paths.
No experimental product code is included.

- [Immutable downloads](https://github.com/obsdoghq/obsdog-releases/releases/tag/v0.1.9)
- [Homebrew formula](https://github.com/obsdoghq/homebrew-tap/blob/main/Formula/obsdog.rb): `brew install obsdoghq/tap/obsdog`
- Standalone update: `obsdog update`; Homebrew update: `brew upgrade obsdoghq/tap/obsdog`.

The public archive SHA-256 is
`7a3f1d14b13b2fe3ae22a52f220815fee40211287c98852e8a10b41d4005b320`.
The manifest also binds the installer, SPDX SBOM, notices, binary terms and exact
private-source revision. Product source remains private.

Full Go race tests, vet, installer negative cases and archive-decoder tests
passed. Anonymous installation using the installer defaults and actual
v0.1.8-to-v0.1.9 updating passed with synthetic knowledge retained; agent search,
open/use events and evaluation attribution remain distinct from human feedback.

This release supports the CLI on Apple silicon macOS. It is not a public Mac
desktop application, a Linux build, or a hosted-service GA announcement.
