# ObsDog CLI v0.2.26

This release lets compatible clients receive remote MCP search, open, completion,
use, evaluation and authoring evidence while preserving its original agent
attribution. It also receives the complete document-maintenance and compensation
profile. Remote declarations remain distinct from local CLI retrieval events;
receiving them does not claim that a local client performed those actions.

A compatible server and authorized connection must provide the corresponding
workflow capabilities. Remote MCP search, reads and permitted writes do not
require installing this CLI. Updating the CLI or plugin does not enable a server
feature, grant OAuth permissions, prepare a Space or start sync.

Pause older writers before receiving this evidence profile into a local library.
Its compatibility fence refuses writers that cannot preserve the canonical
records. Upgrade and reconnect client-owned MCP processes and restart owned
dashboards before resuming them. Do not downgrade the library or remove its
fence. Portable v2 archives retain the producer records; whole-database backups
preserve the full library and validate these records on restore.

Schema 12, the existing ranking policy and local-only use remain unchanged.
Already-transitioned schema-12 libraries need no repeat migration. Older
schema-11 libraries still require the separate, backup-first
[11 → 12 transition](../guides/local-schema-migration.md).

Apple silicon macOS and Linux x86_64 remain supported. The immutable checksum
manifest includes both CLI archives, their separate transition tools, SPDX
inventories and license notices. Installation does not sign in, upload knowledge
or migrate an existing library.

Use `obsdog update` for standalone installations or
`brew upgrade obsdoghq/tap/obsdog` for Homebrew-owned installations.
