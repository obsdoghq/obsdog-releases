# ObsDog CLI v0.2.18

The shared offline/hosted Graph adapts to sparse, clustered and dense document
maps while keeping every loaded document in the same view.

- Tiny maps keep modest circles instead of oversized bubbles. Larger maps cap
  rendered node size; degree still means unique authored neighbors, not quality.
- Dense maps and narrow screens limit node and transparent hit-region sizes by
  actual spacing. Click regions do not overlap adjacent documents. Use the
  complete searchable title/ID index when overview points are too small to tap.
- Representative cluster titles get first consideration, independent documents
  may also have labels, and zooming in increases the title budget. Labels avoid
  other labels and markers instead of displaying every title simultaneously.
- Zoom/pan limits follow the actual map bounds; Fit restores the whole loaded
  map. Resizing, selection and focus clearing retain coordinates and all nodes.
  Large/dense maps use quieter base lines while selected direct links stay clear.

The existing 200-document/500-edge bound, exact source-block links, independent
notes, one-shot/reduced motion and read-only exploration remain unchanged. The
update does not change knowledge data, ranking, sync policy or native apps.

After upgrading, stop and rerun `obsdog dashboard serve` with the same Space and
port flags, then refresh the browser. Reconnect agent sessions that own an
`obsdog mcp` process. Updating the file does not replace running processes.
See the [dashboard guide](../guides/local-dashboard.md).
