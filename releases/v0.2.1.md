# CLI v0.2.1 — current-search consistency

This release isolates current lexical scoring from retained historical snapshots
and synchronized trace chunks. Equivalent reindexing preserves scores and
deterministic tie ordering, and current snapshot selection no longer depends on
wall-clock string ordering. Search JSON identifies its baseline as
`lexical/current-v1`; bounded adaptive activation is unchanged.

Source revisions, historical snapshots, recorded retrievals, evaluations and
comments remain intact. The replaceable serving cache uses the existing schema;
old recorded hits still open their original text. No new numbered database
migration, login or cloud enrollment is required. Keep recoverable backups.

This is a serving-index correctness fix, not a claim of improved benchmark hit
rate. Historical snapshot storage growth, bounded activation history and the
quality of authored navigation links remain separate work. Compare versions
with identical corpus, questions, feedback, initial state and reading budgets.

## Install or update

Apple-silicon macOS CLI only. This is not a native application update.

```sh
# Standalone installation
obsdog update --check
obsdog update

# Homebrew installation — use instead of the standalone updater
brew update
brew upgrade obsdoghq/tap/obsdog
```

Choose one installation method. See the [installation guide](../README.md) for
anonymous first installation and checksum verification. The release includes
license notices, SPDX inventory and an exact source revision identifier.

The release passed the full race-enabled CLI suite, static checks, current-index
invariance and clock-ordering regressions, backup/history/care tests, an anonymous
clean install and a retained-data v0.1.8-to-v0.2.1 update. These are correctness
and distribution checks, not a retrieval-quality benchmark.

The distributed AI [retrieval-authoring guide](https://github.com/obsdoghq/skills/blob/main/plugins/obsdog/skills/maintain/references/retrieval-authoring.md)
explains optional entity overviews, question-to-source links and the difference
between finding a navigation heading and acquiring the actual answer source.
