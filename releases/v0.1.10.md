# CLI v0.1.10

Installer-only correction over v0.1.9. Installation and temporary-directory paths
containing spaces or shell metacharacters are now treated literally during both
executable version checks. Product Go source and dependencies are unchanged;
experimental retrieval features are not included.

- [Immutable downloads](https://github.com/obsdoghq/obsdog-releases/releases/tag/v0.1.10)
- Homebrew: `brew install obsdoghq/tap/obsdog` (update with `brew upgrade obsdoghq/tap/obsdog`).
- Existing standalone installations: `obsdog update`.
- New standalone installations: use this release's `install.sh` and `checksums.txt`.

Local Go race tests, vet, archive-decoder validation, and installer integrity
tests passed, including dry-run, installation and replacement with spaces and
metacharacters in both paths. Existing v0.1.9 artifacts remain unchanged.

After publication, the anonymous installer passed with spaces/metacharacters in
both paths. An actual v0.1.8-to-v0.1.10 update preserved synthetic knowledge and
correct agent search, exposure, use and evaluation attribution.

CLI use, not a public macOS desktop app or hosted-service GA.
