# v0.2.37

This release supports the bounded activity policy and complete retention recovery.

- An explicitly enabled Space preserves current knowledge. Older document versions
  must be both within seven days and among the latest ten including current.
- Raw read/write/search/evaluation details expire seven days after first trusted
  server acceptance. Small UTC daily aggregates retain explicit coverage.
  Original identifiers, hashes, byte counts, acceptance times and outcomes stay
  available as compact evidence; expired full details are explicitly unavailable.
- Recovery verifies the complete checkpoint and subsequent activity updates.
  Expired details cannot return through an old backup or replica. The existing
  retention capability and independent activity capability remain distinct.
- Unresolved local operations and drafts preserve their original identities.
  Recovery does not acknowledge or rebase them automatically. A held reader can
  prevent the first local transition; follow the reported recovery instructions.

Read [history retention and recovery](../guides/history-retention.md). Installing
this release does not enable a server policy, migrate a library or reconnect a
running client. Existing schema12 and fresh schema13 remain supported. Check the
installed CLI and loaded guidance separately.

Standalone archives are provided for macOS arm64 and Linux amd64. Native macOS
execution validation was waived for this release; do not interpret the macOS
archive's presence as a completed native qualification. The public package
contains checksums, platform SPDX files, licenses, notices and source revision.
