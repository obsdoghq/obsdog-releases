# ObsDog CLI v0.2.17

The offline and hosted Graph now show all loaded documents together instead of
switching between connected components. Local use still needs no account or sync.

- Connected groups and independent notes share one settled map and thumbnail.
  Every loaded document remains visible while you search, select or clear focus.
  The title/ID index provides a readable alternative to small overview markers.
- Selecting a node emphasizes only its direct authored neighbors; clicking it
  again clears focus. The camera and coordinates stay in place. Unchanged-data
  refresh preserves the viewport.
- The one-shot entrance follows real adjacency within each connected group.
  Independent notes appear without invented links. Completion follows the last
  visible effect; reduced motion skips spatial animation. Larger maps use a
  lighter entrance rather than continuous physics.
- Explicit user-opened dashboard HTML deep links no longer incorrectly return
  `Cross-site access is disabled`. Cross-site API/search/subresource access,
  embedded frames, foreign Origins and non-loopback Hosts remain blocked.

Exact source-block links, unresolved references, proposed relations, read-only
exploration and the existing 200-node/500-edge limit remain unchanged. Node size
indicates authored neighbor count, not truth or usefulness. This update does not
change search ranking, synchronization policy, database schema or native apps.

After upgrading, stop and rerun `obsdog dashboard serve` with the same Space and
port flags, then refresh the browser. Reconnect agent sessions that own an
`obsdog mcp` process. Updating the file does not replace running processes.
See the [dashboard guide](../guides/local-dashboard.md).
