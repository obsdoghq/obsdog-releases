# ObsDog CLI v0.2.15

This update makes the offline Graph easier to follow and adds optional,
read-only diagnostics. It does not change the graph's layout or search ranking.

- On first load, the Graph shows a brief placeholder only when data takes more
  than a moment to arrive. Actual written links and documents then appear
  once. Refresh keeps the current view in place; reduced-motion settings skip
  the reveal. The placeholder is not a document or inferred connection.
- `obsdog search --no-observe --count-total --query TEXT` optionally counts all
  current matching blocks. This is separate from the frozen 100-candidate
  search window. It does not create a retrieval run or usefulness evidence and
  can take longer on a large Space.
- `obsdog trace recovery` accepts `--expect-document`, `--expect-block`, and
  `--expect-revision` to reject a follow-up hit that is not the intended current
  answer. It compares existing runs; it does not create a recovery score.
- `obsdog care source probe-git --event EVENT_ID --repo LOCAL_CHECKOUT` can
  inspect a full recorded Git commit and path-like section in an explicitly
  supplied matching local GitHub checkout. It never fetches or writes a Care
  verdict. A present file does not prove its claim is still correct.

After upgrading, restart a running `obsdog dashboard serve` process and
reconnect agent sessions that own an `obsdog mcp` process. Replacing the CLI
file does not replace already-running processes.
