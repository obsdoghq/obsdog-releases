# CLI v0.2.5 — bounded observed-memory projection

Apple silicon macOS CLI, stable channel. No account is required for local use.
This is not a macOS desktop application or an iOS release.

## Corrected

Searches whose results were never opened, used or judged remain in the local
append-only history, but no longer consume the 32,768-event Living-memory
scoring-input limit. The memory summary reports their excluded count. Runs with
any selection, use or judgment remain in the bounded projection even if the
observation is later rejected as stale or unbound. Meaningful overflow still
disables adaptation visibly and leaves lexical search available.

The current `chunks_fts` serving index remains intact and current-only. This
patch does not change retrieval ranking weights or delete historical chunks.
Long-term duplication of immutable full-snapshot chunks is a separate open
storage design question.

## Verification boundary

Synthetic tests cover more than 32,768 returned-only starts plus a real useful
sample, meaningful overflow, retained raw events and old corruption fallback.
Full race/vet, archive integrity, anonymous installation and retained-data
upgrade are release gates. These checks establish correctness, not an
independent hit-rate or latency improvement; no benchmark was run for this
patch.

Use one installation owner: `brew upgrade obsdoghq/tap/obsdog`, or standalone
`obsdog update`. The AI plugin is distributed separately.
