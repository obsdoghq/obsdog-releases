# ObsDog CLI v0.2.28

This patch makes local feedback and duplicate-import errors easier to act on.

`obsdog feedback add --help` lists all four kinds and their allowed values:
relevance, usefulness, correctness and freshness. Every kind requires the exact
opened hit; usefulness also requires genuine recorded use. Claim evidence,
review policies and task-outcome judgments remain the caller’s responsibility.
An opened result that was rejected can receive relevance feedback without
inventing use. Uninspected results remain unjudged.

Import refusals now identify whether the existing document matches the source
path, the current content hash, or both. A same-source refusal still applies
when its current revision is unavailable. Errors identify the existing document
without echoing a source path or document contents. Inspect that document first:
a path-only match can mean changed content or unrelated path reuse. Use a
distinct file only for confirmed unrelated notes; otherwise choose a supported
update or an intentional fork. Import remains create-only.

The [agent setup guide](https://github.com/obsdoghq/skills/blob/main/docs/SETUP.md)
and workflows v0.3.22 make authorized, evidence-backed evaluation visible in
resident guidance. Search conclusions distinguish no results, no useful
inspected results, useful evidence and insufficient evidence. Noise remains a
per-hit judgment and can coexist with helpful results. There is no rating quota
or new persisted search-outcome metric.

Schema 12, ranking and existing history remain unchanged. Already-transitioned
schema-12 libraries need no repeat migration. Schema-11 libraries still need the
separate, backup-first [11 → 12 transition](../guides/local-schema-migration.md).

Apple silicon macOS and Linux x86_64 remain supported. The checksum manifest
covers both CLI archives, separate transition tools, SPDX inventories, installer
and license notices. Run `obsdog update` for a standalone installation or
`brew upgrade obsdoghq/tap/obsdog` for Homebrew. Restart client-owned MCP and
dashboard processes to use the new executable. Installation does not sign in,
grant permissions, enable sync or update a desktop app.
