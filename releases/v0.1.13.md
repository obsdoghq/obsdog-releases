# CLI v0.1.13 — hosted login compatibility

This is the recommended release for hosted Personal sync. It includes the
[v0.1.12 history-adoption workflow](v0.1.12.md) and fixes the previous OAuth
decoder rejecting the server's `space_id` response extension after approval.

Unknown OAuth extensions are accepted as required by RFC 6749 §5.1. Duplicate or
malformed fields still fail, and login/refresh verify any returned Space ID
against the exact selected Space before credentials enter the OS store. Error
descriptions and arbitrary server strings are not exposed in diagnostics.

Real owner-authorized device login and Keychain storage passed against the
deployed server. Local data is not uploaded by login or installation. Use v0.1.13
or later for new hosted login; v0.1.12 assets remain unchanged for audit.

Apple silicon macOS CLI only. Source remains proprietary. Desktop and iOS work
remain on hold. Keep private backups before explicitly adopting a whole library.
