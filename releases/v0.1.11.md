# CLI v0.1.11

Personal knowledge works from any directory without `obsdog init`. Commands
default to Personal; `--space personal` or an exact local Space ID makes the
selection explicit. Optional project setup reuses Personal rather than creating
another library for each repository. Ambiguous or broken selections fail visibly.

AI callers can now preserve their attribution on `document import` and
`block update` with `--actor-type agent --actor your-agent`, in addition to
search/open/use and separately attributed feedback.

This is a bounded update over v0.1.10: storage schema, search, sync protocol and
dependencies are unchanged. It neither merges existing libraries nor enables
cloud synchronization. The macOS desktop app and its bundled helper are separate.
