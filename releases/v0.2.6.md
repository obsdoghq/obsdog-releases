# CLI v0.2.6 — local activity and quiet updates

Apple silicon macOS CLI, stable channel. Local use needs no account. This is
not a macOS desktop application or iOS release.

## New

- The local dashboard has a bounded, newest-first Recent activity view. Expand
  a search to inspect its exact recorded retrieval/open/use/feedback sequence;
  creation, updates and structural care appear as separate attributed rows.
  Browsing the feed does not create use or evaluation records.
- Individual timestamps in the dashboard use the viewing browser device's time
  zone and daylight-saving rules. Daily aggregate buckets and comparison
  windows remain explicitly UTC; their boundaries have **not** been shifted.
- The dashboard can show an available CLI update. Successful non-JSON CLI
  commands may also emit one quiet update hint to stderr at most once per 24
  hours, including when an AI agent runs them. JSON and MCP stdout stay clean.
  A bounded public release-metadata check never sends Space content or tokens;
  offline use continues normally. Set `OBSDOG_NO_UPDATE_NOTIFIER=1` to disable
  the automatic check and hint. The dashboard's update panel uses the same
  local cache. Upgrades remain manual and use the installation owner: Brew or
  standalone `obsdog update`.
- Agent block updates require an exact `--base-revision`. If another writer
  changes that block, reread and reconcile rather than overwriting it. Direct
  split/merge/move still need one writer per document or a revision-checked care
  plan; this release does not claim general collaborative editing.

`obsdog insights show --format json` remains for agents and scripts. Explicit
`report create` HTML export remains available; the local dashboard is the
default human view. No ambient command-latency telemetry was added.

## Verification boundary

Full race tests, vet, installer checks, archive decoding, Apple-silicon smoke,
anonymous fresh installation and retained-data upgrade are separate release
gates. These establish functional behavior, not improved retrieval quality or
measured performance. Local data is never uploaded by the update check.
