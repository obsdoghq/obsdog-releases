# Reporting a vulnerability

Please report suspected vulnerabilities privately to jh145478@gmail.com.
Include the ObsDog version, affected platform, a minimal reproduction and the
impact. Do not post access tokens, refresh tokens, documents, account identifiers
or unredacted production logs in public issues.

This initial beta has no formal bug-bounty or response-time commitment.
Only official, checksum-verified release artifacts from this repository are
covered by its download instructions. Product source repositories remain private.
